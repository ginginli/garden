Ano ang Admin Abuse?

Ang Admin Abuse ay isang lingguhang live event sa Garden Horizons kung saan ang mga developer ng laro ay sumasali sa isang aktibong server at gumagamit ng kanilang admin powers para lumikha ng kaguluhan. Sa panahon ng event, maaari silang mag-spawn ng bihirang weather events tulad ng Thunderstorm at Starfall, magbigay ng eksklusibong items sa mga manlalaro, at mag-trigger ng natatanging mutations.

Karaniwang tumatagal ang event ng 1-2 oras at live-streamed sa opisyal na Discord server. Ito ay isa sa pinaka-inaabangan na lingguhang events sa Garden Horizons community.
